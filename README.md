# 🎬 Video Downloader Telegram Bot

যেকোনো ভিডিও লিংক পাঠালে বট সেটা ডাউনলোড করে **Telegram-এর আসল ভিডিও ফাইল** হিসেবে পাঠায়।

## সাপোর্টেড সাইট
YouTube, Instagram, TikTok, Facebook, X/Twitter, Vimeo এবং yt-dlp সাপোর্ট করা আরও অনেক সাইট।

## Render-এ ডিপ্লয় (তোমার আগের প্রজেক্ট রিপ্লেস করতে)

1. এই ফোল্ডারের সব ফাইল তোমার GitHub রিপোতে পুশ করো (পুরনো ফাইল ডিলিট করে)।
2. Render ড্যাশবোর্ডে গিয়ে সার্ভিস **Manual Deploy** বা অটো ডিপ্লয় করো।
3. Environment Variables-এ শুধু `BOT_TOKEN` বসাও।

## লোকাল টেস্ট
```bash
pip install -r requirements.txt
export BOT_TOKEN=তোমার_টোকেন
python main.py
```
