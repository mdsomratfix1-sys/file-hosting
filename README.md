# 📦 FileHub — Telegram-ভিত্তিক ফাইল হোস্টিং

ইমেজ, ভিডিও, অডিও, PDF যেকোনো ফাইল। ফাইল আসল অর্থে **Telegram চ্যানেলে** জমা থাকে (ফ্রি, সীমাহীন স্টোরেজ), আর ওয়েবসাইট শুধু লিংক, লগইন, প্রিভিউ ও ম্যানেজ করে। MySQL লাগে না — ডাটাবেস SQLite।

## কী কী আছে
- রেজিস্ট্রেশন + **টেলিগ্রাম বটে OTP ভেরিফিকেশন**, লগইন/লগআউট
- ওয়েবে ড্র্যাগ-অ্যান্ড-ড্রপ আপলোড (একাধিক ফাইল, প্রগ্রেস বার)
- নিজের ফাইলের তালিকা, সার্চ, প্রিভিউ (ছবি/ভিডিও/অডিও/PDF), ডাউনলোড, নাম বদল, মোছা
- প্রতিটি ফাইলে পাবলিক **শেয়ার লিংক** (`/f/CODE`) + ডাউনলোড কাউন্টার
- ভিডিও/অডিও সিক করা যায় (Range রিকোয়েস্ট সাপোর্ট)
- **টেলিগ্রাম বট**: ফাইল পাঠালে সেভ হয়, শেয়ার লিংক ফেরত দেয়; `/myfiles`, `/help`, অ্যাডমিনের জন্য `/stats`
- **অ্যাডমিন প্যানেল**: ড্যাশবোর্ড (ইউজার/ফাইল/সাইজ/ডাউনলোড), ইউজার ব্লক/আনব্লক/মোছা, সব ফাইল দেখা ও মোছা
- ডাটাবেস **অটো-ব্যাকআপ** প্রাইভেট চ্যানেলে (ফ্রি হোস্টিংয়ে ডিস্ক মুছে গেলেও ডাটা ফেরত আসে)
- লগইনে ব্রুট-ফোর্স সুরক্ষা, শেয়ার করা HTML ফাইল সবসময় ডাউনলোড হিসেবে যায় (XSS ঠেকাতে)

## ⚠️ সীমাবদ্ধতা (জেনে রাখুন)
- **ফাইলের সর্বোচ্চ সাইজ ২০ MB।** Telegram Bot API ২০MB-র বেশি ফাইল ডাউনলোড করতে দেয় না। বড় ফাইলের জন্য নিজের [Local Bot API Server](https://github.com/tdlib/telegram-bot-api) চালিয়ে `TG_API_BASE` সেট করলে লিমিট ~২GB পর্যন্ত যায়।
- Telegram-এর ফাইল লিংক ব্যবহারের নীতিমালা মানতে হবে; কপিরাইট-করা/বেআইনি কন্টেন্ট হোস্ট করবেন না।
- Render ফ্রি প্ল্যানে ৩০ মিনিট ইনএক্টিভ থাকলে সার্ভার ঘুমায়; তখন বট উত্তর দেরিতে দেয়। UptimeRobot-এর মতো সার্ভিস দিয়ে প্রতি ১০ মিনিটে পিং দিলে এড়ানো যায়।

## 🔐 নিরাপত্তা — এখনই করুন
1. আপনার বট টোকেন চ্যাটে শেয়ার হয়ে গেছে। **@BotFather → /revoke** দিয়ে টোকেন বাতিল করে **নতুন টোকেন** নিন।
2. টোকেন, পাসওয়ার্ড কখনো কোডে বা GitHub-এ রাখবেন না। সব সিক্রেট Render/Railway-র **Environment Variables**-এ দিন।
3. ব্যাকআপ চ্যানেলটি **প্রাইভেট** রাখুন (সেখানে সেশন ডাটা থাকে)।

## 🛠 ধাপে ধাপে সেটআপ

### ১) টেলিগ্রাম সেটআপ
1. **@BotFather** → `/newbot` → নতুন বট বানান → টোকেন ও ইউজারনেম নিন।
2. **ফাইল স্টোরেজ চ্যানেল** বানান (Private), বটকে চ্যানেলের **Admin** বানান (Post messages ও Delete messages অনুমতি সহ)। চ্যানেল আইডি (`-100...`) নিন। আপনার দেওয়া `-1003981049123` ব্যবহার করতে পারেন।
3. **ব্যাকআপ চ্যানেল** আলাদাভাবে বানান (Private), বটকে Admin করুন (Pin messages অনুমতি সহ) → তার আইডি `BACKUP_CHAT_ID`।
4. আপনার নিজের টেলিগ্রাম আইডি জানতে **@userinfobot**-এ `/start` দিন → `ADMIN_TELEGRAM_ID`।

### ২) GitHub-এ আপলোড
```bash
git init
git add .
git commit -m "FileHub first commit"
git branch -M main
git remote add origin https://github.com/<আপনার-ইউজারনেম>/filehub.git
git push -u origin main
```
(`.env` ও `data/` `.gitignore`-এ আছে, তাই সিক্রেট যাবে না।)

### ৩) Render-এ ডেপ্লয় (ফ্রি, GitHub দিয়ে লগইন)
1. render.com → **New + → Web Service** → GitHub repo সিলেক্ট করুন। Runtime: **Docker**, Plan: **Free**।
   (অথবা **Blueprint** দিয়ে `render.yaml` ব্যবহার করুন।)
2. **Environment** ট্যাবে এগুলো বসান:

| Key | মান |
|---|---|
| `BOT_TOKEN` | নতুন টোকেন (BotFather থেকে) |
| `BOT_USERNAME` | বটের ইউজারনেম (@ ছাড়া) |
| `CHANNEL_ID` | `-1003981049123` |
| `BACKUP_CHAT_ID` | ব্যাকআপ চ্যানেলের আইডি |
| `ADMIN_USERNAME` | `MR.SOMRAT` |
| `ADMIN_PASSWORD` | `MR.SOMRAT@10` (পরে বদলাবেন) |
| `ADMIN_TELEGRAM_ID` | আপনার টেলিগ্রাম নিউমেরিক আইডি |
| `SITE_URL` | Render দেওয়া URL, যেমন `https://filehub-xxxx.onrender.com` |
| `MAX_UPLOAD_MB` | `20` |

3. Deploy চাপুন। লগে `✅ অ্যাডমিন প্রস্তুত` ও `🤖 বট চালু` দেখলে সফল।
4. পাসওয়ার্ড বদলাতে Render-এ `ADMIN_PASSWORD` বদলে Redeploy করুন (প্রতি চালুতে ওই পাসওয়ার্ড অ্যাডমিনে সেট হয়)।

### ৪) Railway-তে ডেপ্লয় (বিকল্প)
1. railway.app → **New Project → Deploy from GitHub repo**।
2. Variables ট্যাবে উপরের সব Key বসান। `railway.json` Dockerfile ব্যবহার করবে।
3. Settings → Networking → **Generate Domain** → সেই URL-টি `SITE_URL`-এ দিন।
> Railway-র ফ্রি সুবিধা স্থায়ী নয় (ট্রায়াল ক্রেডিট দেয়)। বর্তমান প্ল্যান ও দাম তাদের সাইটে যাচাই করুন।

### ৫) লোকালি চালানো (টেস্টের জন্য)
```bash
npm install
cp .env.example .env   # এরপর .env এ আসল মান বসান
node --env-file=.env index.js     # Node 20.6+
```
ব্রাউজারে `http://localhost:3000` খুলুন।
